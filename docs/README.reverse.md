# reverse

Reverses the order of lines from stdin.

## Examples

```bash
# Reverse file contents
cat file.txt | reverse

# Reverse command output
ls -1 | reverse

# Show git log in chronological order
git log --oneline | reverse
```

## See Also

- `tac` - GNU coreutils reverse (not available on macOS by default)
- `tail -r` - BSD tail with reverse option
